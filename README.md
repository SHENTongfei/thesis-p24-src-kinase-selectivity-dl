# 基于深度学习的 SRC 黏附信号激酶候选配体评价与活性预测

> 围绕 SRC 在肿瘤侵袭转移与骨重建中的作用，用深度学习评价候选配体并预测活性，服务相关病理机制研究。

## 一、方法

- **模型**：JumpingKnowledge 多尺度跳跃连接图网络

- **输入**：分子图（原子节点 + 化学键边，RDKit 解析 SMILES 得到）
- **训练规模**：2499 条样本，2 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
